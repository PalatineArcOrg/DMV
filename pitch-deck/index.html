Dead Man's Vault is an autonomous crypto inheritance protocol for Solana. Configure beneficiaries, confirm heartbeats, and know your assets are protected — no backend, no intermediaries, no trust required.

How It Works
Five stages. One tap to stay alive.
Set up your vault once. Then just confirm a heartbeat periodically. If you stop, the protocol takes over.
0
Normal
Vault active. Heartbeat confirmed. All clear. Your assets are safe and your beneficiaries are on standby.
Check in weekly, bi-weekly, or monthly
1
Reminder
Heartbeat overdue. Push notifications sent to you. One tap resets everything back to normal.
Duration: 3 days
2
Alert
Still no response. Notifications increase in frequency. Emergency contacts alerted.
Duration: 7 days
3
Warning
Final countdown. Hourly notifications. This is your last chance to confirm liveness.
Duration: 7 days
4
Execution
Irreversible. The agent autonomously distributes SOL and tokens from your vault to each beneficiary via on-chain instructions. Vault closed. Agent key destroyed.
Autonomous · No wallet interaction
Features
Built for real-world crypto inheritance.
Every feature designed around one principle: your assets should be protected without relying on anyone else.
🔒
TEE-Secured Agent Key
A dedicated agent key stored in Seeker's hardware secure enclave handles heartbeats and execution autonomously. Your owner wallet stays untouched.
💰
Vault PDA Asset Storage
Deposit SOL and SPL tokens directly into your vault PDA. Withdraw anytime. At Stage 4, the agent distributes to each beneficiary via on-chain instructions.
🔄
Crash-Proof Execution
Every execution step is checkpointed to SQLite before proceeding. App crashes, device restarts — execution resumes exactly where it left off.
📊
Live Portfolio Tracking
Token balances via Helius DAS API, USD prices from dual oracles (Pyth + Jupiter), 24h price changes, DeFi position detection across 10 protocols.
🤝
On-Chain Beneficiary Whitelist
The program only sends assets to wallets you've pre-approved. Up to 20 beneficiaries with basis-point share allocation.
🔍
Full Transparency
Every heartbeat, every distribution, every state change — all recorded on-chain. Execution logs with transaction signatures link directly to Solana Explorer.
