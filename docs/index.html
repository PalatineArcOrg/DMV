How It Works
Five stages. One tap to stay alive.
Set up your vault once. Confirm a heartbeat periodically. If you stop, the protocol takes over.
0
Normal
Heartbeat confirmed. All clear. Assets safe and beneficiaries on standby.
Weekly / bi-weekly / monthly
1
Reminder
Overdue. Push notifications sent to owner. One tap resets to normal.
Duration: 3 days
2
Alert
No response. Frequency increases. Emergency contacts alerted.
Duration: 7 days
3
Warning
Final countdown. Hourly notifications. Last chance to confirm liveness.
Duration: 7 days
4
Execution
Irreversible. Assets distributed autonomously on-chain. Vault closed. Agent key destroyed.
Autonomous · No wallet interaction
Features
Built for real-world crypto inheritance.
Every feature designed around one principle: your assets should be protected without relying on anyone else.
🔒
TEE-Secured Agent Key
Dedicated agent key in Seeker's hardware enclave. Handles heartbeats and execution autonomously. Owner wallet stays untouched.
💰
Vault PDA Storage
Deposit SOL and SPL tokens into your vault PDA. Withdraw anytime. At Stage 4, agent distributes to each beneficiary on-chain.
🔄
Crash-Proof Execution
Every execution step checkpointed to SQLite. App crashes, device restarts — execution resumes exactly where it left off.
📊
Live Portfolio Tracking
Token balances via Helius DAS, dual-oracle USD pricing (Pyth + Jupiter), DeFi position detection across 10 protocols.
🤝
On-Chain Whitelist
Program only sends to pre-approved wallets. Up to 20 beneficiaries with basis-point share allocation.
🔍
Full Transparency
Every heartbeat, distribution, and state change recorded on-chain. Execution logs link directly to Solana Explorer.
On-Chain Program
Minimal program. Maximum security.
The program only enforces who can transfer, where transfers go, and when they're allowed. All complex logic lives in the mobile app.
  • 🛡
    13 Instructions
    Initialize, update, heartbeat, SOL/SPL distribution, record execution, rotate agent, revoke, withdraw, close — all with strict signer and state guards.
  • 🔒
    19 Error Codes
    Covering interval validation, share allocation, signer authorization, vault state guards, beneficiary whitelist, immutability protection, and lifecycle management.
  • ✅
    34 Tests Passing
    Happy paths, all error cases, rotate_agent security guards, SOL/SPL distribution, vault withdraw, close_executed_vault, double-execution prevention, revoke/close lifecycle.
  • 🔧
    Mutable or Immutable
    Choose whether your vault can be updated/revoked, or make it permanent. Agent rotation is always allowed for device migration.

Why Dead Man's Vault
What makes us different.
  • ⚓
    Truly Serverless
    No backend server, no cloud functions, no intermediaries. Everything runs on-device or on-chain. Zero infrastructure to maintain or trust.
  • 📱
    Built for Seeker
    First-class Solana Mobile integration. Agent key secured in TEE hardware enclave. Owner signs via Seed Vault MWA. Designed for the mobile-first crypto user.
  • 🛡
    Owner Supremacy
    Owner can always override, withdraw, revoke, or rotate. The agent key operates within strict on-chain constraints. Even if the device is compromised, the program enforces the rules.
  • 💡
    Graduated Escalation
    17+ days of warnings before execution. Multiple chances to confirm liveness. Any heartbeat at Stages 1–3 resets to normal. Stage 4 is the only irreversible action.
